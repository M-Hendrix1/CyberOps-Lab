# Runbooks

Write repeatable setup steps here. Keep each runbook scoped to one task and record the exact software version and validation result.

## Planned runbooks

- Windows host and VirtualBox readiness
- Isolated VirtualBox network creation and validation
- Ubuntu Server VM creation and baseline
- Wazuh deployment and health checks
- Windows and Linux endpoint onboarding

## Runbook template

For each procedure, include:

1. **Status:** Planned, In progress, or Verified
2. **Purpose and prerequisites**
3. **Steps performed**, with version numbers and non-sensitive configuration
4. **Expected result**
5. **Validation performed and observed result**
6. **Recovery or rollback notes**
7. **Date and evidence link**

Never include passwords, tokens, recovery keys, or unredacted sensitive network details.
