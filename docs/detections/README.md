# Detection engineering

**Status: Planned.** No detections are claimed as implemented until they are tested in the lab.

For each detection, record:

- Detection name and purpose
- Data sources and prerequisites
- MITRE ATT&CK tactic and technique
- Expected behavior and safe test procedure
- Wazuh rule or query reference
- Expected alert and observed result
- False-positive considerations and tuning
- Evidence link and date validated

Keep simulations within the isolated lab. Do not run tests against systems you do not own or have permission to assess.
