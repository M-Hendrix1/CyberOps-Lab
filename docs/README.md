# Documentation

This folder contains the design, build notes, detection work, and sanitized evidence for the CyberOps Lab.

## Pages

- [Architecture and scope](architecture.md): planned components, trust boundaries, and validation checks.
- [Runbooks](runbooks/README.md): repeatable host and VM setup procedures.
- [Detection engineering](detections/README.md): ATT&CK mapping, rule logic, test cases, and tuning notes.
- [Incident response](incident-response/README.md): triage and response workflow for lab exercises.
- [Evidence](evidence/README.md): index of sanitized screenshots, outputs, and results.

## Recording status

For each component, label it **Planned**, **In progress**, or **Verified**. Use Verified only after documenting a check that another person could repeat. Keep secrets, personal data, and sensitive network details out of this public repository.
