# Incident response exercises

**Status: Planned.** Use this page to record controlled, lab-only exercises.

For each exercise, document:

1. Scenario and scope
2. Triggering alert and affected lab endpoint
3. Triage questions and evidence collected
4. Containment decision and rationale
5. Recovery steps, if applicable
6. Lessons learned and follow-up tickets
7. Sanitized evidence links

Keep a clear timeline. Do not include credentials, personal data, or details that expose non-lab systems.
